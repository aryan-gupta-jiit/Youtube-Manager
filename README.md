# Youtube-Manager
YouTube Video Manager! This Python-based program is designed to manage a list of YouTube videos

I’m excited to share a basic yet functional project I recently created — YouTube Video Manager! This Python-based program is designed to manage a list of YouTube videos, including features to:

📝 List all videos in a visually appealing and colorful format.
➕ Add new videos with details like name and duration.
✏️ Update the details of existing videos.
❌ Delete videos you no longer need.
💾 Persist all changes locally using a JSON file.
🛠️ What Makes This Project Special?
User Interface Enhancements:

Leveraged libraries like pyfiglet and ANSI escape codes to create a visually engaging experience in the terminal.
Each option and video listing is presented with bold and colorful text, making the program more interactive and fun!
Core Features:

File-based persistence using Python's json module ensures your data remains intact even after exiting the app.
Intuitive options for CRUD operations (Create, Read, Update, Delete) to simulate real-world application functionality.
Learning Journey:

This project helped me strengthen my understanding of file handling, data manipulation, and Python libraries for terminal styling.
It’s a stepping stone to more advanced projects with enhanced functionality, such as database integration or GUI/CLI development.
